Wiring it in — four steps

  1. Copy cockpit/cockpit.css and cockpit/cockpit.js into your assets and load both on the Schedule page.
  2. Delete the orange region — the Schedule for: Sunset line, the four stat cards, and the Previous/Today/Next + range + refresh + Create booking row. Leave one <div id="day-cockpit"></div> where they were.
  3. Call renderCockpit(el, data) with the day payload, passing your existing click handlers in on. It returns { update, destroy } — call update(next) after a booking is created or the date changes.
  4. Map colors to your tokens if you have them: every value is a CSS variable on .cockpit (--ck-olive, --ck-alert, --ck-now-bg…), so a theme override is a few lines.
